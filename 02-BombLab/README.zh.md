## 注意事项（本机实测，先看这里）

你的环境：WSL2 + Ubuntu 24.04，纯命令行，64 位 x86-64。

**已实测确认：**

| 项目 | 状态 |
| --- | --- |
| `bomb` 二进制 | 64 位 ELF，可直接运行，无需 32 位库 |
| `gdb` | 已安装（15.1） |
| `objdump` / `strings` | 已安装 |
| `gcc` / `make` | 已安装 |
| 上报功能 | 自学版已禁用，炸弹不会连接任何服务器，随便炸、不扣分 |

**基本用法：**

```bash
./bomb              # 从标准输入逐行读取字符串
./bomb answer.txt   # 从文件读取，读到文件尾后转回标准输入
```

每拆掉一关，把该关答案追加进 `answer.txt`，下次运行就不用重敲前面已经拆过的答案。

**拆弹必备工具：**

```bash
objdump -t bomb   # 符号表：列出所有函数、全局变量名及其地址
objdump -d bomb   # 反汇编全部代码
strings bomb      # 打印所有可打印字符串
gdb ./bomb        # 单步调试、下断点、查看寄存器与内存
man ascii         # 查 ASCII 码表
```

**几个注意点：**

- 炸弹共 6 关（phase 1~6）。每拆一关，炸弹打印 `Phase N defused...`；全部拆完打印恭喜信息。
- 炸弹会忽略空行输入。
- 不要用暴力穷举——课程版每炸一次扣 0.5 分且会刷爆评分服务器；自学版虽不扣分，但穷举也不是正路。
- `bomb.c` 里 `#include` 的 `support.h`、`phases.h` 没有随包提供（正常，bomb.c 只是主流程参考，真正的拆弹逻辑都在二进制里）。
- 参考分值（课程版，自学版无评分）：Phase 1~4 各 10 分，Phase 5~6 各 15 分，满分 70。

## 快速上手流程

1. 先跑一次看看：`./bomb`
2. 用 `objdump -d bomb` 反汇编，配合 `gdb` 查看每一关的逻辑。
3. 用 `gdb` 下断点、查看寄存器与内存，找出每关要求的字符串。
4. 把答案逐行写入 `answer.txt`，用 `./bomb answer.txt` 验证。
5. 6 关全部拆完即完成本实验。
